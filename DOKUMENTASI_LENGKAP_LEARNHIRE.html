1. Konsep & Arsitektur Sistem LearnHire

LearnHire adalah platform web full-stack terintegrasi yang menggabungkan dua ekosistem krusial: portal lowongan pekerjaan (Job Board) dan portal pelatihan keterampilan (Course LMS). Platform ini dirancang untuk menjawab permasalahan tingginya kesenjangan keterampilan (skill gap) antara lulusan/pencari kerja dengan kualifikasi riil yang dibutuhkan oleh industri.

Nilai Inovasi Utama ("Learn" + "Hire"):
Di portal kerja konvensional, pelamar yang ditolak karena minim kualifikasi hanya menerima status gagal tanpa solusi. Di LearnHire, sistem menyediakan jalur pengembangan diri (Talent Development). Jika pelamar belum memenuhi kualifikasi suatu lowongan, platform langsung merekomendasikan kursus in-house yang relevan untuk menutup kesenjangan tersebut.

1.1 Alur Pelamaran: Filter Bertingkat (Two-Stage Screening)

LearnHire menerapkan mekanisme kemitraan resmi (B2B Talent Partnership) dengan instansi/perusahaan tujuan. Alur seleksi di web terbagi menjadi dua tahap:

  1. Tahap 1 - Administrasi & Pre-Screening (Admin Web LearnHire): Ketika pengguna melamar pekerjaan di sistem, berkas berstatus pending. Admin LearnHire bertindak sebagai kurator awal yang memeriksa kelengkapan berkas, format portofolio, dan kompetensi dasar. Berkas yang layak diubah statusnya menjadi reviewed dan diteruskan ke HRD instansi mitra.
  2. Tahap 2 - Keputusan Akhir (HRD Instansi Rekanan): HRD instansi memeriksa kandidat yang telah lolos kurasi tahap 1. Karena kuota terbatas, HRD menentukan kandidat terpilih. Admin LearnHire kemudian memperbarui status akhir menjadi accepted (lolos ke wawancara/tahap lanjutan) atau rejected (tidak terpilih).

1.2 Arsitektur Aliran Data (Clean Architecture)

Sistem dibangun dengan prinsip pemisahan tanggung jawab (Separation of Concerns). Frontend tidak pernah mengakses database MySQL secara langsung, melainkan seluruh komunikasi data wajib melalui antarmuka REST API:

Browser Pengguna (HTML5/CSS3/JS)  ⇄  Fetch API  ⇄  REST API (Express Router)  ⇄  Controllers  ⇄  Models  ⇄  MySQL (Pool Connection)

3. Penjelasan Detail Setiap Berkas (File-by-File Breakdown)

3.1 Root & Dokumentasi Dasar

.gitignore
Menginstruksikan Git untuk tidak menyertakan berkas-berkas sensitif atau direktori berukuran besar seperti node_modules/, berkas kredensial .env, serta berkas log eksekusi ke repositori Git.
README.md
Panduan komprehensif bagi pengembang dan penguji yang berisi deskripsi aplikasi, prasyarat sistem (Node.js & XAMPP), langkah setup database, panduan menjalankan backend, tabel akun demo, ringkasan API, dan solusi pemecahan masalah (troubleshooting).

3.2 Database Layer (folder: database/)

database/database.sql
Skrip SQL DDL & DML mandiri yang siap diimpor langsung via phpMyAdmin. Berisi instruksi pembuatan database learnhire_db, 9 tabel berelasi (dengan Primary Key, Foreign Key, dan Unique Constraint), serta data awalan (7 pengguna, 6 perusahaan, 12 lowongan kerja, 10 kursus, dan data transaksi lamaran). Password akun demo telah di-hash menggunakan algoritma bcryptjs (cost factor 10).

3.3 Backend Configuration & Core (folder: backend/)

backend/server.js
Berkas utama Express.js. Mengatur konfigurasi middleware keamanan (Helmet dengan CSP permissive untuk font eksternal, CORS untuk komunikasi lintas origin, dan Express JSON parser). Melayani penyajian berkas statis frontend (folder ../frontend), me-mount rute API pada path /api, serta menangani Single Page Application fallback untuk rute non-API.
backend/package.json
Mendefinisikan metadata project backend serta daftar dependensi resmi: express, mysql2, cors, dotenv, bcryptjs, jsonwebtoken, helmet, dan dev-dependency nodemon untuk hot-reloading selama pengembangan.
backend/.env & backend/.env.example
Menyimpan konfigurasi variabel lingkungan lokal: port server (3000), host database (localhost), port MySQL (3306), nama database (learnhire_db), user root, serta kunci rahasia tanda tangan digital JWT (JWT_SECRET).
backend/config/database.js
Membentuk koneksi database berbasis Connection Pool menggunakan library mysql2. Mengaktifkan metode pool.promise() agar seluruh pemanggilan query SQL di layer model dapat dieksekusi secara asinkron (async/await).

3.4 Backend Middleware Layer (folder: backend/middleware/)

backend/middleware/auth.middleware.js
Berisi tiga fungsi penjaga keamanan rute:
  • verifyToken: Mengekstrak token dari header Authorization: Bearer <token>, memvalidasi masa berlaku dan signature JWT, serta menyematkan payload user ke req.user.
  • isAdmin: Memeriksa apakah req.user.role === 'admin' untuk melindungi endpoint khusus administrator (CUD lowongan, CUD kursus).
  • optionalAuth: Mengekstrak token jika ada, namun tidak menggagalkan request jika token tidak disediakan (berguna untuk endpoint publik).
backend/middleware/error.middleware.js
Pusat penanganan error terpusat (Centralized Error Handling). Menyediakan fungsi notFound (mengembalikan HTTP 404 berformat JSON standar) dan errorHandler (menangkap unhandled exception, mengembalikan HTTP 500 berformat JSON tanpa membocorkan stack trace mentah ke pengguna).

3.5 Backend Models Layer (folder: backend/models/)

Layer model bertugas murni berinteraksi dengan database MySQL menggunakan Prepared Statements (parameterized queries) guna mencegah celah keamanan SQL Injection.

backend/models/user.model.js
Menyediakan fungsi manipulasi entitas pengguna: findAll, findById, findByEmail (menyertakan password untuk verifikasi login), create (menerima nama, email, password terenkripsi, telepon, dan role), update (menggunakan sintaks SQL COALESCE untuk mendukung pembaruan parsial profil tanpa menimpa data yang tidak diisi), dan delete.
backend/models/job.model.js
Mengelola data lowongan pekerjaan. Fungsi findAll mendukung filter dinamis berdasarkan kata kunci pencarian (judul/deskripsi), ID kategori, tipe pekerjaan (Full-time/Part-time/Contract/Internship), dan status aktif dengan melakukan JOIN ke tabel companies dan job_categories.
backend/models/company.model.js
Menyediakan operasi data master perusahaan mitra penyedia lowongan: nama, industri, lokasi, logo, dan deskripsi institusi.
backend/models/course.model.js
Mengelola data kursus online. Menyediakan query findAll dengan JOIN ke course_categories, mendukung filter pencarian, filter kategori, dan filter level keahlian (Beginner, Intermediate, Advanced).
backend/models/application.model.js
Mengelola data transaksi pelamaran kerja pengguna. Memiliki fungsi findByUserId untuk menampilkan lamaran milik user tertentu, checkExisting untuk mencegah user melamar lowongan yang sama lebih dari satu kali, create untuk menyimpan surat lamaran, update untuk mengubah status seleksi, dan delete untuk pembatalan lamaran.
backend/models/enrollment.model.js
Mengelola keikutsertaan kursus online. Fungsi create secara otomatis menginkremen kolom total_students pada tabel courses. Fungsi update mengelola persentase progres belajar dan otomatis mencatat timestamp completed_at jika status diset menjadi 'completed'.
backend/models/category.model.js
Menyediakan fungsi pembacaan kategori pekerjaan (findAllJobCategories) dan kategori pelatihan kursus (findAllCourseCategories) untuk kebutuhan dropdown filter pada antarmuka frontend.
backend/models/support.model.js
Mengelola tiket bantuan pengguna (Customer Service). Menyediakan fungsi pembuatan pesan kendala, pengambilan riwayat pesan pengguna, pembaruan balasan solusi dari admin, dan penghapusan tiket.

3.6 Backend Controllers Layer (folder: backend/controllers/)

Layer controller bertindak sebagai koordinator logika bisnis: memvalidasi input klien, memanggil model terkait, dan mengembalikan respon JSON seragam berformat { success: true/false, message: "...", data: ... } beserta status code HTTP yang sesuai.

backend/controllers/auth.controller.js
  • register: Memvalidasi kelengkapan input, memeriksa keunikan email, mengenkripsi password dengan bcryptjs, menyimpan data ke database, dan menghasilkan token JWT.
  • login: Memeriksa keberadaan email, mencocokkan password menggunakan bcrypt.compare, dan menghasilkan token JWT berisi payload { id, name, role } jika valid.
  • getProfile & updateProfile: Membaca dan memperbarui informasi akun user yang sedang login.
backend/controllers/job.controller.js & course.controller.js
Menangani request publik untuk melihat seluruh katalog (dengan parameter query) maupun detail per ID. Membatasi aksi tambah, edit, dan hapus hanya untuk pengguna ber-role 'admin'.
backend/controllers/application.controller.js
Mengatur proses pelamaran. Menolak pengiriman lamaran ganda pada lowongan yang sama. Membatasi pengguna biasa agar hanya dapat melihat dan menghapus lamaran milik akunnya sendiri, sementara akun admin memiliki hak akses untuk melihat seluruh lamaran masuk dan memperbarui statusnya.
backend/controllers/enrollment.controller.js
Menangani pendaftaran kelas online gratis/berbayar, memvalidasi pendaftaran ganda, serta menyediakan endpoint pembaruan progres belajar (persentase kelulusan).
backend/controllers/dashboard.controller.js
Mengumpulkan statistik ringkasan sistem secara real-time dari database (Total Lowongan Aktif, Total Kursus Aktif, Total Pengguna Terdaftar, dan Total Lamaran Masuk) untuk ditampilkan pada kartu statistik beranda.

3.7 Backend Routes Layer (folder: backend/routes/)

backend/routes/index.js
Master router yang menggabungkan seluruh sub-rute ke bawah prefix /api (seperti /api/auth, /api/jobs, /api/courses, /api/applications, /api/enrollments, /api/support, dan /api/dashboard).
backend/routes/*.routes.js (9 file rute)
Mendefinisikan pemetaan HTTP Verb (GET, POST, PUT, DELETE), penyematan middleware autentikasi (verifyToken, isAdmin), dan penghubungan ke fungsi controller spesifik.

3.8 Frontend Core & Assets (folder: frontend/assets/)

frontend/assets/css/style.css
Pusat styling aplikasi dengan tema visual Dark Glassmorphism sesuai prototipe Canva:
  • Palette warna: Navy gelap (#0a0e27), Secondary (#1a1f4e), Gradient ungu-ke-biru (#7c3aed ke #3b82f6).
  • Komponen kartu transparan dengan efek blur latar belakang (backdrop-filter: blur(10px)).
  • Dekorasi visual lingkaran cahaya melayang animasi (floating animated orbs).
  • Sistem grid responsif untuk Desktop (multi-kolom + fixed sidebar), Tablet (sidebar mengecil), dan Mobile (hamburger menu bar atas).
  • Styling formulir dengan glow fokus, status badge warna-warni, progress bar bergradien, dan toast notifikasi.
frontend/assets/js/api.js
Helper HTTP terpusat berbasis fetch(). Mengotomatisasi penyisipan header Authorization: Bearer <token> dari localStorage pada setiap request yang membutuhkan autentikasi, serta menangani error sesi kedaluwarsa (HTTP 401) dengan mengarahkan pengguna kembali ke halaman login.
frontend/assets/js/auth.js
Modul pengelola sesi autentikasi pada sisi klien. Menyediakan fungsi getToken, setToken, isLoggedIn, checkAuth (guard untuk halaman privat), checkGuest (guard agar user yang sudah login tidak bisa membuka halaman login/register kembali), logout, dan parseJwt untuk mengekstrak data role dan nama dari payload token.
frontend/assets/js/app.js
Pustaka utilitas antarmuka bersama:
  • showNotification(message, type): Menampilkan toast notifikasi animasi di sudut kanan atas.
  • formatCurrency(amount): Mengonversi angka integer menjadi format mata uang Rupiah (IDR) standar Indonesia.
  • formatDate(dateString): Mengonversi tanggal ISO menjadi format penanggalan berbahasa Indonesia.
  • loadSidebar() & updateUserInfo(): Menginjeksi komponen sidebar secara asinkron, menandai menu aktif, serta menampilkan nama dan lencana status (ADMIN atau USER) secara akurat.

4. Struktur Relasional Database MySQL (learnhire_db)

Database learnhire_db mengadopsi struktur relasional yang ternormalisasi untuk menjamin integritas data:

Nama Tabel Kolom-Kolom Utama Kunci & Relasi (Constraints) Peran Bisnis
users id, name, email, password, phone, address, avatar, bio, skills, cv_url, role PRIMARY KEY (id)
UNIQUE (email)		 Menyimpan data identitas pencari kerja dan administrator sistem. Password tersimpan dalam hash bcrypt.
companies id, name, logo, description, location, website, industry PRIMARY KEY (id) Menyimpan data institusi/perusahaan mitra penyedia lowongan pekerjaan.
job_categories id, name, icon PRIMARY KEY (id) Kategori bidang lowongan (Teknologi, Desain, Marketing, Keuangan, Rekayasa, Data Science).
jobs id, company_id, category_id, title, description, requirements, salary_min, salary_max, location, type, status PRIMARY KEY (id)
FK (company_id) → companies(id)
FK (category_id) → job_categories(id)		 Katalog lowongan pekerjaan yang dibuka oleh perusahaan mitra.
job_applications id, user_id, job_id, cover_letter, cv_url, status PRIMARY KEY (id)
FK (user_id) → users(id)
FK (job_id) → jobs(id)
UNIQUE KEY (user_id, job_id)		 Transaksi lamaran kerja. Unique constraint mencegah user melamar lowongan yang sama secara berulang.
course_categories id, name, icon PRIMARY KEY (id) Kategori pelatihan kursus (Programming, UI/UX, Data Science, Business, Language).
courses id, category_id, title, description, instructor, duration, level, price, rating, total_students, status PRIMARY KEY (id)
FK (category_id) → course_categories(id)		 Katalog pelatihan keterampilan terstruktur dengan instruktur industri.
course_enrollments id, user_id, course_id, progress, status, enrolled_at, completed_at PRIMARY KEY (id)
FK (user_id) → users(id)
FK (course_id) → courses(id)
UNIQUE KEY (user_id, course_id)		 Data keikutsertaan pelatihan user, melacak persentase progres belajar (0-100%).
support_messages id, user_id, subject, message, reply, status PRIMARY KEY (id)
FK (user_id) → users(id)		 Komunikasi dua arah antara pengguna dengan tim administrator terkait bantuan teknis.

5.2 Cara Menjalankan Aplikasi Secara Mandiri

  1. Aktifkan XAMPP: Buka XAMPP Control Panel, pastikan service Apache dan MySQL berada pada status running (Port 80 dan Port 3306).
  2. Buka phpMyAdmin: Buka browser di http://localhost/phpmyadmin/. Impor berkas database/database.sql (Database learnhire_db dan 9 tabel akan terisi otomatis).
  3. Jalankan Backend Server: Buka PowerShell / Terminal pada folder backend, lalu jalankan: 
    npm run dev  (atau: node server.js)
  4. Akses Antarmuka Web: Buka browser di http://localhost:3000. Seluruh fitur dapat langsung diuji secara lokal.
